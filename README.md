# 向野 · 旅行规划 App

一个以手机使用为主的中文旅行规划网页应用。可以从互动地球和七大洲目的地发现灵感，创建行程、安排每日地点、查看地图与讲解、记录预算，并在出发清单和当地语言练习里逐步准备旅行。

## 本地运行

需要 Node.js 18 或更新版本。无需安装依赖：

```bash
node serve.cjs
```

打开 `http://127.0.0.1:8788/`。应用源码和静态资源位于 `dist/`；手机浏览器在同一局域网访问时，需要自行将服务地址和监听方式改为适合本地网络的配置。

## 数据和限制

- 行程、清单和费用默认保存在当前浏览器的本地存储中。公开仓库不含个人行程，换设备不会自动同步。
- 地点封面保存在本地；部分地图、搜索、天气和开放信息依赖外部网络服务，信息可能变化。实际路线、票价、签证和预订请向官方渠道核对。
- 地图标记与估算不能替代实时导航或正式预订。
- `dist/travel-plan/` 融合了 [Travel-Plan-Page](https://github.com/do-tongxue/Travel-Plan-Page) 的代码，保留其许可证与第三方说明。
